# 酷狗概念版每日 VIP · Loon

从已登录的酷狗概念版保存签到配置，每天核对领取记录后领取当天 VIP。支持单账号，默认每天设备本地时间 **06:00** 执行。

## 文件

| 文件 | 用途 |
| --- | --- |
| `kugou-concept-vip.plugin` | Loon 插件、定时任务及 HTTPS 解密规则 |
| `capture.js` | 从 App 成功响应中校验签名，保存查询及领取所需配置 |
| `claim.js` | 查询记录、手动或定时领取、后台更新登录凭证 |
| `test/native.test.cjs` | 使用模拟 Loon API 的本地回归测试 |

## 已安装用户升级

仓库迁移后，请将 Loon 中的插件订阅地址改为下方的新安装地址，再更新插件和远程脚本。已有的 `kgcv.native.v1` 接口配置和 `kgcv.claim.v1` 防重复领取状态继续使用，**无需重新捕获或测试领取**。

日常保留“后台凭证更新”的默认设置。升级时如果之前开过“配置捕获”，请关闭现在的“重新捕获配置”。领取时间沿用已保存的参数，需要每天 06:00 执行时设为 `0 6 * * *`。

已保存 Web 查询配置的用户可直接开启定时领取，也可以随时手动领取。

## 首次使用

1. 在 Loon 中添加插件：

   ```text
   https://raw.githubusercontent.com/changeCat/proxy-plugins/main/loon/kugou-concept-vip/kugou-concept-vip.plugin
   ```

2. 使用 Loon 3.5.1 (983) 或更新版本，安装并信任 HTTPS 解密证书，启用插件及其 MitM 域名。
3. 登录**酷狗概念版**，打开一次 **VIP 领取记录页**。看到 Loon 通知 **“签到配置已就绪”** 即完成。如果提示“签到配置待补全”，按通知完成剩余一步。
4. 想每天定时领取，就打开“启用自动领取”。想立即领取，就在 Loon 点“手动核对并领取 VIP”。

切换账号或修复配置时，先暂停自动领取，开启“重新捕获配置”，再打开目标账号的 VIP 领取记录页。看到“签到配置已就绪”后关闭重新捕获，按需恢复定时。

## 日常使用

- **自动领取**按设备本地时间定时执行，默认每天 06:00。
- **手动核对并领取 VIP** 立即执行相同的领取流程，自动领取开关关闭时也可使用。
- **仅查询 VIP 记录**：只查询，不提交领取，不改变当天领取状态。
- **后台凭证更新**：打开概念版时监听普通请求，同一 App、账号和设备的新 Token 通过只读查询验证后，更新已有配置。无需特意进入 VIP 页面；App 要求登录时先重新登录。监听会产生 Loon 运行记录。

## 领取规则与常见问题

- 先查询月度记录，只有明确显示今天未领取时才提交一次领取。当天已确认成功时直接跳过。
- 发出领取请求前保存待确认状态。超时、业务失败或中断后，当天只复查记录，不重复提交；请到 App 查看实际权益。
- 查询失败、记录结构无法识别或配置不完整时停止领取。错误详情会脱敏后写入通知和日志。
- 凭证更新只接受同账号、同设备的新 Token，验证失败保留原配置；每分钟最多验证一次。切换账号、设备变化或配置失效时需重新捕获。
- 首次打开记录页没有收到通知时，确认 Loon 已启用插件、HTTPS 解密和通知，再重新进入记录页。已有可用配置时，正常打开记录页不会重复提醒；可点“仅查询 VIP 记录”确认。
- 配置和凭证只保存在手机的 Loon 本地存储；不要公开 Token、Cookie、完整请求或脚本存储内容。
