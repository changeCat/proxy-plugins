# QQ 阅读签到与视频福利提醒 · Loon

每天按设备本地时间提醒一次。点按 Loon 通知后，插件尝试打开本机 QQ 阅读的福利页，使用 App 已登录的账号。签到、观看视频和领取奖励需要在 App 内完成。

## 本地试用

1. 准备 Loon 3.5.1 (983) 或更新版本，在 iOS 中允许 Loon 发送通知。
2. 把 [qq-reading-welfare.js](qq-reading-welfare.js) 放入 Loon 的本地脚本目录，保留文件名。在 Loon 中添加本地插件 [qq-reading.plugin](qq-reading.plugin)。
3. 先运行「测试签到提醒」，点按通知，查看是否打开福利页。QQ 阅读版本可能影响跳转，如果只打开首页，请在 App 内进入福利页。也可以使用 QQ 阅读自带的一键签到小组件。
4. 默认每天 08:00 提醒。可在插件参数中更改「提醒时间」或关闭「每日签到提醒」。

## 核对奖励

- **签到**　查看当天的签到格。显示「今日已签」即表示当天已签到。「再领」是额外入口，「今日已获赠币」含当天其他活动奖励。
- **视频**　在 Loon 运行「查看视频福利」并点按通知。进入福利页的「看小视频领好礼」，按页面要求观看，核对本次发放的是赠币、积分还是其他奖励。
